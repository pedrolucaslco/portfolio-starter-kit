**Feira** is a grocery list PWA focused on budget tracking, real-time sharing, and offline-first reliability. Built with vanilla JS and IndexedDB, it works without internet and syncs via Supabase when available.

## Key features

- **Offline-first** — IndexedDB local persistence with Supabase sync
- **Real-time sharing** — items sync between users in the same space
- **Budget tracking** — monthly budget, weekly suggested spend, card closing date
- **Active purchase session** — timer, total on finish, recently bought section
- **Custom sections** — organize items by category with drag-and-drop
- **Meals tab** — isolated meal lists with one-click copy to shopping list
- **Purchase history** — spending chart, median line, period filtering
- **Dark/light themes** — DaisyUI emerald (light) and dim (dark)

## Stack

HTML, CSS, JavaScript vanilla, IndexedDB, Service Worker, DaisyUI/Tailwind, Supabase (optional), Vercel.
